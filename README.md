# homebrew-cp

Homebrew tap for competitive programming tools.

```sh
brew install paras-ydv/cp/cp-mac
```

| Formula | What it does |
|---|---|
| [cp-mac](https://github.com/Paras-ydv/cp-mac) | `bits/stdc++.h`, pb_ds and rope on Apple Clang, plus `cprun` |

On Apple Silicon, run `cp-mac link` once after installing so Apple Clang finds the headers.
